# coolBio · AQA AS & A-Level Biology Revision Portal

> **coolBio** is an ultra-fast, minimalist past paper question bank, cheatsheet repository, and interactive revision system designed specifically for **AQA AS and A-Level Biology (7401 / 7402)**.

---

## 🧬 Key Features

1. **Specification & Curriculum Browser:**
   - Organized strictly by the official AQA 7401/7402 specification sections across **3.1 Biological molecules** through **3.8 The control of gene expression**, plus **Required Practicals (RP1–RP12)**.
   - Live mark counters and topic mastery tracking.

2. **Past Paper Question Bank:**
   - Multi-dimensional filtering by **Level** (AS / A-Level), **Topic**, **Paper / Year**, **Skill** (Maths, Practical, Analysis, Extended Response), and **Minimum Marks**.
   - Side-by-side split view for questions, figures, and official mark schemes.
   - Individual question PDF printing and batch question worksheet generation.
   - Star/Bookmark system and Mark-as-Done mastery tracking (saved persistently to `localStorage`).

3. **High-Yield Revision Cheatsheets:**
   - Dedicated specification checklists and structured notes for all 37 topics (`3.1.1`–`3.8.4` + `RP`).
   - Includes essential definitions, biological tests, equations, and required practical methods (RP1–RP12).
   - Instant 1-click **Export to PDF / Print** formatting.

4. **Interactive Practice & Flashcards:**
   - High-impact flashcards covering key definitions, biochemical tests, pathways, and practicals.
   - Spaced repetition mode, starred filter, and mastery tracking.

5. **Teacher's Revision & Classroom Hub:**
   - **Classroom Quiz Game:** Projector-ready interactive quiz game with Team 1 vs Team 2 scoreboard, countdown timer, sound effects, and celebratory confetti.
   - **Question & Worksheet Generator:** Assemble custom worksheets and mock exams by topic and target marks with printable ruled answer lines and full teacher mark keys.

6. **Biology Maths & Data Sheet Reference:**
   - Built-in reference modal accessible from any page: magnification, rate, cardiac output, Simpson's Index of Diversity, Hardy-Weinberg equations, statistical tests ($\chi^2$, $t$-test, Spearman's rank), Lincoln Index, and SI prefixes.

## 🚀 Running Locally or Deploying

Because coolBio is built with pure standards-based HTML5, CSS3, and vanilla JavaScript, it has **zero build steps** and **zero dependencies**.

### Local Preview:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

### GitHub Pages Deployment:
In your repository settings:
1. Navigate to **Settings > Pages**.
2. Under **Build and deployment > Branch**, select `main` / `(root)`.
3. Click **Save**.
