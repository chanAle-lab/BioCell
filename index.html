AQA Biology Maths, Equations & Statistical Reference

Key Biological Equations

Magnification: M = Image size / Actual size
Mitotic Index: Cells in mitosis / Total cells
Cardiac Output: CO = Heart Rate × Stroke Volume
Pulmonary Ventilation: PV = Tidal Volume × Breathing Rate
Simpson's Index (D): D = N(N − 1) / Σn(n − 1)
Net Primary Production: NPP = GPP − R
Consumer Net Production: N = I − (F + R)
Hardy-Weinberg: p + q = 1  |  p2 + 2pq + q2 = 1
Lincoln Index: N = (n1 × n2) / m
Chromatography Rf: Pigment distance / Solvent front

Statistical Tests & When to Use Them

Test When to Use Null Hypothesis Decision (p = 0.05)
Chi-squared (χ2) Comparing observed vs expected frequencies in categories (e.g. genetic crosses, choice chambers). If χ2 ≥ critical value (df = n − 1), reject H0 (difference is significant).
Student's t-test Comparing the means of two normally distributed continuous datasets. If |t| ≥ critical value (df = n1 + n2 − 2), reject H0.
Spearman's rank (rs) Testing correlation between two ranked/continuous variables (e.g. transect data). If |rs| ≥ critical value (N pairs), reject H0 (significant correlation).
